プライバシーポリシー

推し通帳（iOS アプリ）

サポート

要約

  • アカウント登録は不要です。氏名・メールアドレスなど、身元が分かる情報は集めません。
  • 開発者はサーバーを持ちません。登録した推し・記録・会費・写真と設定は端末の中にあります。
  • アプリが通信するのは、App 内課金と、使い方の統計（バージョン 1.1.0 以降）だけです。どの通信にも、登録した内容は含まれません。
  • 使い方の統計は、アプリの改善のため、画面を開いた回数や購入画面を開いたきっかけなどを、個人を特定しない形で送るものです。「設定」→「プライバシー」でいつでもオフにできます。
  • 広告・トラッキングは行いません。位置情報は要求しません。
  • 誰をどれだけ推しているかという記録が、開発者に届くことはありません。

本ポリシーは、個人開発者 Yutaro Hayashi が提供する iOS アプリ「推し通帳」および本サイトに適用されます。

1. 端末の中にだけ保存する情報

推し通帳はアカウント登録を必要とせず、登録なしで全機能が動作します。登録した推し（名前・推し色・写真・推し始めた日）、記録（日付・金額・種類・メモ）、会費（名前・金額・支払いの周期・支払日・解約日）と各種設定は、いずれも端末の中に保存されます。

開発者はサーバーを運用しておらず、登録内容を受け取る仕組みはありません。氏名・メールアドレス・電話番号・連絡先・広告識別子（IDFA）などの端末に固有の識別子を取得することはありません。銀行口座やクレジットカード、ファンクラブなどのサービスのアカウントと連携することもありません。金額や支払日は、すべて利用者ご自身が入力したものです。

不具合の調査のため、保存や通知の予約などの処理が失敗したときに、処理の種類とエラーの番号を端末のシステムログに記録します。推しの名前や金額は含めず、アプリがこの記録を外部へ送ることもありません。

2. 写真

推しに写真を設定するときは、iOS の写真の選択画面を使います。アプリに渡るのは利用者が選んだ1枚だけで、写真ライブラリを読み取る許可は求めません。選んだ写真は小さくして端末の中に保存し、外部へ送ることはありません。

Pro の「今年の推し活まとめカード」を画像として写真に保存するときだけ、写真への追加の許可を求めます。この許可は、カードの画像を写真に保存するためだけに使います。保存した画像や共有した画像がどこへ渡るかは、利用者が共有の画面で選んだ保存先・共有先によります。開発者には送られません。

3. 使い方の統計（バージョン 1.1.0 以降）

アプリをより使いやすくし、どこで迷ったり購入をやめたりしているかを知るため、アプリの使われ方の統計を送ります。初めから送る設定になっており、「設定」→「プライバシー」の「使い方の統計を送る」をオフにすると、それ以降は送りません。

  • 送り先は PostHog, Inc.（米国）のアクセス解析のサービス（PostHog Cloud、米国のデータセンター）です。
  • 送るのは次の情報です。
    • アプリを開いた・ほかのアプリから戻ったこと、初めて開いたこと（そのときすでに推しの登録があったかどうか）、開いたタブとまとめカード
    • 推し・会費・記録を追加したこと（最初の1件かどうか）と、推しの人数・解約していない会費の件数の段階（例:「1人」「3人以上」）
    • 購入画面を開いたことと、どこから開いたか
    • 購入を始めたことと、購入・復元の結果（完了・キャンセル・承認待ち・失敗・確認できない）、買い切りか年額か
    • まとめカードの「保存・共有」を押したことと、全員分か推し1人か、金額を隠したかどうか
    • Pro かどうか、アプリと iOS のバージョン、App Store と TestFlight のどちらから入れたか
    • アプリが初めて開いたときに作る乱数の ID と、利用のまとまりを表す乱数の ID
  • 推しの名前・推し色・写真・推し始めた日、記録の金額・日付・種類・メモ、会費の名前・金額・支払日、設定の内容は送りません。誰をどれだけ推しているかは分かりません。
  • 乱数の ID は、氏名やメールアドレス、Apple Account、ほかのアプリの ID とは結びつきません。アプリを削除して入れ直すと新しい ID になります。他社のアプリや Web サイトをまたいだ追跡には使いません。
  • PostHog には、IP アドレスを保存しない設定をしています。国や地域の推定も止めています。端末の機種名・言語・地域も送りません。
  • 「使い方の統計を送る」をオフにしたときは、オフにしたことだけを、その場限りの乱数の ID で 1 回送ります（オフにする方の割合を知るためです。それまでの使い方とは結びつきません）。そのあとは何も送らず、端末に残っていた送る前の統計と ID も削除します。もう一度オンにすると、新しい ID で始まります。
  • 統計はアプリの改善の検討のためにだけ使い、第三者へ販売・提供することはありません。

このページは、電気通信事業法に基づく外部送信（利用者の端末から外部へ情報を送ること）の公表を兼ねています。送信先は PostHog, Inc.、送信される情報と利用目的は上記のとおりです。

4. 通知

会費の支払日の前にお知らせする通知は、端末の中で予約して表示する通知です。通知の許可は、この通知を端末に表示するためだけに使用します。通知を送るためのサーバーは無く、通知用の端末の識別子を取得することもありません。

5. トラッキングと広告

A/Bテスト基盤、広告識別子（IDFA）、広告ネットワークのいずれも組み込んでいません。広告は表示しません。サードパーティ製のSDKは使用しておらず（使い方の統計も、アプリ自身の仕組みで送っています）、他社のアプリやWebサイトをまたいで利用者を追跡することもありません。

6. 位置情報

位置情報の利用許可を求めることはありません。取得も利用もしません。

7. 購入に関する情報

Pro の購入（買い切り・年額）は Apple の App 内課金を通じて行われます。決済は Apple が処理し、開発者がクレジットカード番号・住所・Apple Account などの決済情報を受け取ることはありません。購入状態の確認は Apple の StoreKit を通じて端末上で行われます。アプリが行う通信は、この購入に関するものと、「3. 使い方の統計」の通信だけです。購入を始めたことと結果は、使い方の統計として送ります（3章。決済の情報は含みません）。

8. Apple から開発者に提供される情報

Apple は App Store Connect を通じて、ダウンロード数・売上・クラッシュレポートといった統計情報を開発者に提供します。これらは個人を識別しない集計された情報であり、クラッシュレポートなどの一部は、利用者が iOS の設定で「App デベロッパと共有」を有効にしている場合にのみ提供されます。開発者がアプリの利用状況を知る手段は、この経路と「3. 使い方の統計」だけです。

9. お問い合わせをいただいた場合

サポート宛にメールをお送りいただいた場合、その本文と送信元のメールアドレスを開発者が受け取ります。アプリの「お問い合わせ」から作成したメールには、アプリのバージョン・iOS のバージョン・端末のモデル名があらかじめ本文に入っています（送信前に確認でき、消すこともできます）。メールの受信には Gmail（Google LLC）を利用しています。

いただいた内容はお問い合わせへの回答と、その後の不具合対応のためにのみ利用します。営業目的で利用したり、第三者へ提供したりすることはありません。対応に必要な期間を過ぎたものは削除します。削除のご希望があればお知らせください。

10. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。身元が分かる情報を集めないため、子どもから氏名やメールアドレスなどを取得することもありません。

11. データの削除と利用者の権利

登録した内容と設定は端末内にあり、開発者はそれを保持していません。そのため、削除は利用者ご自身で完結します。

  • 記録は、アプリ内で1件ずつ削除できます。推しを削除すると、その推しの記録と会費も一緒に削除されます
  • アプリを削除すると、端末内に保存されたデータと設定も削除されます
  • 通知と写真への追加の許可は、iOS の「設定」からいつでも取り消せます
  • 使い方の統計は、アプリの「設定」→「プライバシー」でいつでもオフにできます。オフにすると、端末に残っていた送る前の統計と乱数の ID も削除されます
  • 端末のバックアップ（iCloud バックアップなど）を利用している場合、アプリのデータは Apple の仕組みによってそのバックアップに含まれます。バックアップの管理は iOS の「設定」から行えます

開発者が保持するアカウントは存在しないため、退会手続きは必要ありません。送信済みの使い方の統計には身元が分かる情報が無く、開発者にもどの統計がどなたのものか分からないため、個別の開示や削除には応じられません。すでにお送りいただいたお問い合わせメールの削除をご希望の場合のみ、下記の連絡先へお知らせください。
