Shizukuno（YouTube チャンネル）と投稿ツール「Shizukuno Uploader」

English ・ Shizukuno について

要約

  • 投稿ツールは、運営者本人が自分のチャンネルに動画を投稿するためだけに使います。ほかの方に配布・提供していません。
  • ほかの方の個人データを収集・保存・共有しません。
  • Google アカウントの認可情報は、運営者のパソコンのキーチェーンにだけ保存します。運営者はサーバーを持ちません。
  • このサイトはアクセス解析・広告・トラッキングを行いません。

本ポリシーは、個人の Yutaro Hayashi が運営する YouTube チャンネル「Shizukuno」、その動画の投稿に使うツール「Shizukuno Uploader」、および本サイトに適用されます。

1. 投稿ツール「Shizukuno Uploader」とは

Shizukuno Uploader は、運営者が自分のパソコンだけで動かす投稿ツールです。YouTube API サービスを通じて、Shizukuno のチャンネルに動画をアップロードし、サムネイルを設定します。ほかの方に配布・提供しておらず、運営者以外の方が利用することはありません。

2. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールの利用には YouTube 利用規約が適用され、Google によるデータの取り扱いは Google プライバシー ポリシーに従います。

本ツールが Google に求める権限は、運営者のチャンネルへの動画のアップロードと、その動画のサムネイルの設定に必要な範囲に限ります。投稿先が Shizukuno のチャンネルであることを確かめるために、運営者自身のチャンネルの基本情報（チャンネル ID など）を参照することがあります。ほかの方のチャンネル、動画、コメント、登録者の情報を取得することはありません。

3. 本ツールが扱う情報と保存場所

  • 運営者の Google アカウントの認可情報（OAuth のアクセストークンとリフレッシュトークン）: 運営者のパソコンの macOS キーチェーンにだけ保存します。
  • 投稿の記録（動画 ID、URL、投稿日時）: 同じ動画を二重に投稿しないために、運営者のパソコンに保存します。

運営者はサーバーを運用しておらず、これらの情報を第三者に送信・共有・販売することはありません。送信先は、投稿のために通信する Google（YouTube）だけです。

4. 視聴者の方の情報

動画の視聴、コメント、チャンネル登録などは YouTube 上で行われ、Google のプライバシー ポリシーに従って取り扱われます。運営者は YouTube Studio を通じて、再生回数や視聴者層などの集計された統計情報を受け取りますが、個人を特定する情報は受け取りません。コメントは YouTube 上で公開されます。

本ツールが視聴者の方の情報を取得することはありません。

5. 認可の取り消しとデータの削除

本ツールへの認可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。取り消すと、本ツールは YouTube にアクセスできなくなります。運営者のパソコンに保存した認可情報は、取り消しや利用の終了の際に削除します。

本ツールはほかの方のデータを保持していないため、運営者以外の方が削除を申請する必要はありません。お問い合わせメールの削除をご希望の場合は、下記の連絡先へお知らせください。

6. お問い合わせをいただいた場合

メールでお問い合わせいただいた場合、その本文と送信元のメールアドレスを運営者が受け取ります。メールの受信には Gmail（Google LLC）を利用しています。

いただいた内容はお問い合わせへの回答のためにのみ利用します。営業目的で利用したり、第三者へ提供したりすることはありません。対応に必要な期間を過ぎたものは削除します。

7. 子どものプライバシー

本チャンネルは子ども向けに制作したものではありません。本ツールは視聴者の方の個人データを収集しないため、子どもから個人データを取得することもありません。

8. 本サイトについて

本ページは GitHub Pages（GitHub, Inc.）で配信しています。ページの閲覧時には、配信元である GitHub 側で IP アドレス等が記録される場合があります。運営者はそのアクセスログを受け取っていません。本サイトはアクセス解析や Cookie による追跡を行っていません。

9. 本ポリシーの変更

内容を変更した場合は、更新日を添えて本ページに掲載します。本ページに掲載されているものが常に最新版です。
