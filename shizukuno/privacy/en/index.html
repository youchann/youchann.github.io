Privacy Policy

Shizukuno (YouTube channel) and its upload tool, Shizukuno Uploader

日本語 · About Shizukuno

Summary

  • The upload tool is used only by the channel operator to post videos to their own channel. It is not distributed or offered to anyone else.
  • No one else's personal data is collected, stored, or shared.
  • Google account authorization data is stored only in the Keychain on the operator's own computer. The operator runs no servers.
  • This website uses no analytics, no ads, and no tracking.

This policy applies to the YouTube channel "Shizukuno" operated by individual Yutaro Hayashi, to "Shizukuno Uploader", the tool used to post its videos, and to this website.

1. What Shizukuno Uploader is

Shizukuno Uploader is an upload tool that the operator runs only on their own computer. Through YouTube API Services, it uploads videos to the Shizukuno channel and sets their thumbnails. It is not distributed or offered to anyone else, and no one other than the operator uses it.

2. Use of YouTube API Services

This tool uses YouTube API Services. Use of this tool is subject to the YouTube Terms of Service, and Google handles data in accordance with the Google Privacy Policy.

This tool requests the following two permissions from Google.

  • Manage your YouTube videos (youtube.upload): used to upload videos to the operator's channel and to set thumbnails for those videos.
  • View your YouTube account (youtube.readonly, read-only): used to confirm that the destination is the Shizukuno channel, to check that the same video has not already been uploaded, and to confirm that the title, description, privacy setting, and processing status of an uploaded video are as intended. It reads only the operator's own channel and its videos.

It never retrieves information about anyone else's channels, videos, comments, or subscribers.

3. Information the tool handles and where it is stored

  • Authorization data for the operator's Google account (OAuth access and refresh tokens): stored only in the macOS Keychain on the operator's computer.
  • Upload records (video ID, URL, and upload time): stored on the operator's computer to avoid uploading the same video twice.

The operator runs no servers and never sends, shares, or sells this information to third parties. The only party the tool communicates with is Google (YouTube), for the purpose of uploading.

4. Information about viewers

Watching videos, commenting, subscribing, and similar activities take place on YouTube and are handled under Google's privacy policy. Through YouTube Studio, the operator receives aggregated statistics such as view counts and audience demographics, but no information that identifies individuals. Comments are public on YouTube.

This tool never retrieves information about viewers.

5. Revoking authorization and deleting data

Authorization for this tool can be revoked at any time from the third-party access page in your Google Account security settings. Once revoked, the tool can no longer access YouTube. The authorization data stored on the operator's computer is deleted when authorization is revoked or the tool is no longer used.

Because the tool holds no one else's data, no one other than the operator needs to request deletion. If you would like an inquiry email you sent to be deleted, contact us at the address below.

6. If you contact us

If you email us, the operator receives your message and the sending email address. Email is received via Gmail (Google LLC).

What you send is used only to answer your inquiry. It is never used for marketing or provided to third parties, and it is deleted once it is no longer needed.

7. Children's privacy

This channel is not made for children. Since the tool collects no personal data about viewers, no personal data is collected from children either.

8. About this website

This page is served by GitHub Pages (GitHub, Inc.). GitHub may record information such as IP addresses when the page is served. The operator does not receive those access logs. This site uses no analytics and no tracking cookies.

9. Changes to this policy

If this policy changes, the updated version will be posted on this page along with the date of the update. The version shown here is always the current one.
