Shizukuno（雫野）

雨や雪の降る静かな架空の町「雫野」の、季節ごとの風景と音楽を届ける YouTube チャンネルです。

English ・ プライバシーポリシー

チャンネル

youtube.com/@Shizukuno

作業・勉強・読書・休息のお供になる、2〜3 時間の長尺 BGM を投稿しています。雫野の町の風景を背景に、穏やかな音楽と雨や雪の環境音を重ねています。

AI 生成について

動画の音楽・環境音・背景イラストは、すべて AI で生成しています。実在のアーティストや楽曲を模したものではありません。各動画の説明欄に、使用したツールを記載しています。

投稿ツールについて

動画の投稿には、運営者が自分のパソコンだけで使う投稿ツール「Shizukuno Uploader」を使っています。このツールは YouTube API サービスを通じて、Shizukuno のチャンネルに動画をアップロードし、サムネイルを設定します。ほかの方に配布・提供するものではありません。

ツールが扱う情報については、プライバシーポリシーに記載しています。
