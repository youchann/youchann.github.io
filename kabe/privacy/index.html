プライバシーポリシー

Kabe（iOS アプリ）

English ・ サポート

要約

  • アカウント登録は不要です。個人データを収集しません。
  • 開発者はサーバーを持ちません。アプリのデータは端末の中にあります。
  • アクセス解析・広告・トラッキングを行いません。位置情報は要求しません。
  • ブロック対象として選んだアプリが何であるかは、Apple の設計により開発者にも分かりません。

本ポリシーは、個人開発者 Yutaro Hayashi が提供する iOS アプリ「Kabe」および本サイトに適用されます。

1. 収集しない情報

Kabe はアカウント登録を必要とせず、登録なしで全機能が動作します。アプリグループ・ブロックのルール・変更待機の状態・集中セッションの状態・各種設定は、いずれも端末の中に保存されます。

開発者はサーバーを運用しておらず、アプリから個人データを受け取る仕組みそのものがありません。氏名・メールアドレス・電話番号・連絡先・写真・端末の固有IDを取得することはありません。

2. スクリーンタイム（ファミリーコントロール）の利用

Kabe は Apple のスクリーンタイム関連API（Family Controls / ManagedSettings / DeviceActivity）を利用してアプリをブロックします。初回起動時にスクリーンタイムの利用許可を求めますが、この許可はご自身の端末上でアプリをブロックするためだけに使用します。

ブロック対象として選択されたアプリの情報は、Apple の設計により匿名のトークンとしてのみ扱われます。開発者を含む第三者が「どのアプリを選んだか」を知ることはできず、その情報が端末の外部に送信されることもありません。アプリの利用時間などのスクリーンタイムの統計を開発者が受け取ることもありません。

3. トラッキングと広告

アクセス解析SDK、A/Bテスト基盤、広告識別子（IDFA）、広告ネットワークのいずれも組み込んでいません。広告は表示しません。サードパーティ製のSDKは使用しておらず、他社のアプリやWebサイトをまたいで利用者を追跡することもありません。

4. 位置情報

位置情報の利用許可を求めることはありません。取得も利用もしません。

5. 購入に関する情報

Pro の購入は Apple の App 内課金を通じて行われます。決済は Apple が処理し、開発者がクレジットカード番号・住所・Apple ID などの決済情報を受け取ることはありません。購入状態の確認は Apple の StoreKit を通じて端末上で行われます。

6. Apple から開発者に提供される情報

Apple は App Store Connect を通じて、ダウンロード数・売上・クラッシュレポートといった統計情報を開発者に提供します。これらは個人を識別しない集計された情報であり、クラッシュレポートなどの一部は、利用者が iOS の設定で「App デベロッパと共有」を有効にしている場合にのみ提供されます。開発者はこの経路以外にアプリの利用状況を知る手段を持ちません。

7. フィードバックフォーム

アプリ内および本サイトのサポートページからリンクしているフィードバックフォームは、Google フォーム（Google LLC）を利用しています。フォームに入力された内容は Google のプライバシーポリシーに従って取り扱われます。フォームで氏名やメールアドレスなどの個人情報の入力を求めることはありません。

8. お問い合わせをいただいた場合

サポート宛にメールをお送りいただいた場合、その本文と送信元のメールアドレスを開発者が受け取ります。メールの受信には Gmail（Google LLC）を利用しています。

いただいた内容はお問い合わせへの回答と、その後の不具合対応のためにのみ利用します。営業目的で利用したり、第三者へ提供したりすることはありません。対応に必要な期間を過ぎたものは削除します。削除のご希望があればお知らせください。

9. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。そもそも個人データを収集していないため、子どもから個人データを取得することもありません。

10. データの削除と利用者の権利

アプリのデータは端末内にあり、開発者はそれを保持していません。そのため、削除は利用者ご自身で完結します。

  • グループやブロックは、アプリ内で個別に削除できます（ルールを緩める変更にあたるため、待機時間が必要です）
  • アプリを削除すると、端末内に保存された設定も削除されます
  • スクリーンタイムの利用許可は、iOS の「設定」からいつでも取り消せます

開発者が保持するアカウントは存在しないため、退会手続きや開発者への開示請求は必要ありません。すでにお送りいただいたお問い合わせメールの削除をご希望の場合のみ、下記の連絡先へお知らせください。

11. 本サイトについて

本ページは GitHub Pages（GitHub, Inc.）で配信しています。ページの閲覧時には、配信元である GitHub 側でIPアドレス等が記録される場合があります。開発者はそのアクセスログを受け取っていません。本サイトはアクセス解析やCookieによる追跡を行っていません。

12. 本ポリシーの変更

内容を変更した場合は、更新日を添えて本ページに掲載します。本ページに掲載されているものが常に最新版です。
