まいつき（iOS アプリ）

サポート

要約

  • アカウント登録は不要です。氏名・メールアドレスなど、身元が分かる情報は集めません。
  • 開発者はサーバーを持ちません。登録したサブスクと設定は端末の中にあります。
  • アプリが通信するのは、為替レートの取得（1日1回）、App 内課金、使い方の統計（バージョン 1.1.0 以降）、テンプレートの報告（バージョン 1.2.0 以降。利用者が選んだときだけ）だけです。テンプレートの報告のほかは、どの通信にも、登録したサブスクの内容は含まれません。
  • 使い方の統計は、アプリの改善のため、画面を開いた回数や購入画面を開いたきっかけなどを、個人を特定しない形で送るものです。「設定」→「プライバシー」でいつでもオフにできます。
  • 広告・トラッキングは行いません。位置情報は要求しません。
  • どのサービスにいくら払っているかという登録内容が、開発者に届くことはありません。ただし、テンプレートの古い料金や、テンプレートに無いサービスを「開発者に知らせる」で送ったときは、その報告の内容だけが届きます（4章）。

本ポリシーは、個人開発者 Yutaro Hayashi が提供する iOS アプリ「まいつき」および本サイトに適用されます。

1. 端末の中にだけ保存する情報

まいつきはアカウント登録を必要とせず、登録なしで全機能が動作します。登録したサブスクの内容（名前・金額・通貨・支払い周期・請求日・カテゴリ・状態・アイコン画像）と各種設定は、いずれも端末の中に保存されます。

開発者はサーバーを運用しておらず、登録内容を受け取る仕組みはありません（利用者が選んで送るテンプレートの報告を除きます。4章）。氏名・メールアドレス・電話番号・連絡先・広告識別子（IDFA）などの端末に固有の識別子を取得することはありません。銀行口座やクレジットカード、各サービスのアカウントと連携することもありません。金額や請求日は、すべて利用者ご自身が入力したものです。

不具合の調査のため、保存や通知の予約などの処理が失敗したときに、処理の種類とエラーの番号を端末のシステムログに記録します。サブスクの名前や金額は含めず、アプリがこの記録を外部へ送ることもありません。

2. 為替レートの取得

ドルなどの外貨で登録したサブスクを、設定した通貨に換算して合計するため、アプリは為替レートを取得します。

  • 接続先は Frankfurter（api.frankfurter.dev）です。欧州中央銀行が公表する参考レートを配信している、無料の公開サービスです。
  • アプリを開いたとき（ほかのアプリから戻ったときを含む）に、前回の取得から24時間以上たっていれば1回取得します。
  • アプリが送るのは「最新のレートをください」という要求だけで、すべての通貨のレートをまとめて受け取ります。登録したサブスクの名前・金額・通貨、設定、端末の識別子は送りません。外貨のサブスクがあってもなくても同じ要求を送るため、要求から外貨を使っているかどうかも分かりません。
  • 通信のしくみ上、接続先には IP アドレスと、アプリ名や OS の種類といった通信に付く情報が届きます。Frankfurter は、個人データ・IP アドレス・リクエストの URL を収集も記録もしないと公表しています（frankfurter.dev、2026年11月16日に確認）。開発者がこの通信の内容を受け取ることはありません。
  • 取得したレートとその日付は端末の中に保存します。通信できないときは、前回取得したレート、それも無いときはアプリに含まれているレートで換算します。

サブスクのテンプレート（サービス名・料金・ロゴ）はアプリに含まれています。テンプレートを選ぶときや、ロゴを表示するときに通信することはありません。

3. 使い方の統計（バージョン 1.1.0 以降）

アプリをより使いやすくし、どこで迷ったり購入をやめたりしているかを知るため、アプリの使われ方の統計を送ります。初めから送る設定になっており、「設定」→「プライバシー」の「使い方の統計を送る」をオフにすると、それ以降は送りません。

  • 送り先は PostHog, Inc.（米国）のアクセス解析のサービス（PostHog Cloud、米国のデータセンター）です。
  • 送るのは次の情報です。
    • アプリを開いた・ほかのアプリから戻ったこと、初めて開いたこと（そのときすでに登録があったかどうか）、開いたタブ
    • 購入画面を開いたことと、どこから開いたか（登録数の上限、通知のタイミングなど）
    • 購入・復元を始めたことと、その結果（完了・キャンセル・承認待ち・失敗）、買い切りか月額か
    • サブスクを追加したことと、テンプレートから追加したかどうか、登録の件数（件数そのものと、0件・1〜2件・3〜5件・6件以上の段階）
    • Pro かどうか、アプリと iOS のバージョン、App Store と TestFlight のどちらから入れたか
    • アプリが初めて開いたときに作る乱数の ID と、利用のまとまりを表す乱数の ID
  • 登録したサブスクの名前・金額・通貨・請求日・カテゴリ・メモ・アイコン、設定の内容、書き出したファイルの中身は送りません。
  • 乱数の ID は、氏名やメールアドレス、Apple Account、ほかのアプリの ID とは結びつきません。アプリを削除して入れ直すと新しい ID になります。他社のアプリや Web サイトをまたいだ追跡には使いません。
  • PostHog には、IP アドレスを保存しない設定をしています。そのため、国や地域の推定も行いません。端末の機種名・言語・地域も送りません。
  • 「使い方の統計を送る」をオフにしたときは、オフにしたことだけを、その場限りの乱数の ID で 1 回送ります（オフにする方の割合を知るためです。それまでの使い方とは結びつきません）。そのあとは何も送らず、端末に残っていた送る前の統計と ID も削除します。もう一度オンにすると、新しい ID で始まります。
  • 統計はアプリの改善の検討のためにだけ使い、第三者へ販売・提供することはありません。

このページは、電気通信事業法に基づく外部送信（利用者の端末から外部へ情報を送ること）の公表を兼ねています。送信先は PostHog, Inc.、送信される情報と利用目的は上記のとおりです。

4. テンプレートの報告（バージョン 1.2.0 以降）

アプリに含まれているテンプレート（サービス名と料金）を新しく保つため、サブスクを追加する画面から、テンプレートの古い料金や、テンプレートに無いサービスを開発者に知らせられます。初めから送らない設定で、利用者が「開発者に知らせる」を押し、送る内容を確かめて「知らせる」を選んだときだけ、その1件を送ります。

  • 送り先は、使い方の統計と同じ PostHog, Inc.（米国）のサービス（PostHog Cloud、米国のデータセンター）です。
  • 送るのは次のどちらかです。
    • テンプレートの料金の報告: テンプレートのサービスとプラン、通貨、支払い周期、利用者が入力した金額、テンプレートの金額
    • テンプレートに無いサービスの報告: 利用者が入力したサービスの名前
  • 送るたびに、その場限りの乱数の ID を使います。使い方の統計の ID、アプリのバージョン、Pro かどうかは付けず、使い方の統計やほかの報告とは結びつきません。使い方の統計をオフにしていても、選んだ報告は送れます。
  • サービスの名前は入力したとおりに送られます。名前に個人的な内容が含まれる場合は、送らないでください。
  • IP アドレスは保存せず、国や地域の推定も行いません。
  • 報告はテンプレートの修正と追加のためにだけ使い、第三者へ販売・提供することはありません。

電気通信事業法に基づく外部送信の公表としては、送信先は PostHog, Inc.、送信される情報と利用目的は上記のとおりです。

5. 通知

請求日やトライアル終了の前にお知らせする通知は、端末の中で予約して表示する通知です。通知の許可は、この通知を端末に表示するためだけに使用します。通知を送るためのサーバーは無く、通知用の端末の識別子を取得することもありません。

6. 写真

サブスクのアイコンに画像を設定するときは、iOS の写真の選択画面を使います。アプリに渡るのは利用者が選んだ1枚だけで、写真ライブラリ全体へのアクセス許可は求めません。選んだ画像は小さくして端末の中に保存し、外部へ送ることはありません。

7. データの書き出しと読み込み

「データを書き出す」で作るファイルには、登録したサブスクの内容と、設定したアイコン画像が含まれます。ファイルは利用者が選んだ保存先・共有先にだけ渡り、開発者には送られません。ファイルは暗号化されていないため、共有する相手や保存する場所にご注意ください。

8. トラッキングと広告

A/Bテスト基盤、広告識別子（IDFA）、広告ネットワークのいずれも組み込んでいません。広告は表示しません。サードパーティ製のSDKは使用しておらず（使い方の統計も、アプリ自身の仕組みで送っています）、他社のアプリやWebサイトをまたいで利用者を追跡することもありません。

9. 位置情報

位置情報の利用許可を求めることはありません。取得も利用もしません。

10. 購入に関する情報

Pro の購入（買い切り・月額）は Apple の App 内課金を通じて行われます。決済は Apple が処理し、開発者がクレジットカード番号・住所・Apple Account などの決済情報を受け取ることはありません。購入状態の確認は Apple の StoreKit を通じて端末上で行われます。アプリが行う通信は、この購入に関するものと、「2. 為替レートの取得」「3. 使い方の統計」「4. テンプレートの報告」の通信だけです。購入を始めたことと結果は、使い方の統計として送ります（3章。決済の情報は含みません）。

11. Apple から開発者に提供される情報

Apple は App Store Connect を通じて、ダウンロード数・売上・クラッシュレポートといった統計情報を開発者に提供します。これらは個人を識別しない集計された情報であり、クラッシュレポートなどの一部は、利用者が iOS の設定で「App デベロッパと共有」を有効にしている場合にのみ提供されます。開発者がアプリの利用状況を知る手段は、この経路と「3. 使い方の統計」「4. テンプレートの報告」だけです。

12. お問い合わせをいただいた場合

サポート宛にメールをお送りいただいた場合、その本文と送信元のメールアドレスを開発者が受け取ります。アプリの「お問い合わせ」から作成したメールには、アプリのバージョン・iOS のバージョン・端末のモデル名があらかじめ本文に入っています（送信前に確認でき、消すこともできます）。メールの受信には Gmail（Google LLC）を利用しています。

いただいた内容はお問い合わせへの回答と、その後の不具合対応のためにのみ利用します。営業目的で利用したり、第三者へ提供したりすることはありません。対応に必要な期間を過ぎたものは削除します。削除のご希望があればお知らせください。

13. 子どものプライバシー

本アプリは13歳未満の子どもを対象としていません。身元が分かる情報を集めないため、子どもから氏名やメールアドレスなどを取得することもありません。

14. データの削除と利用者の権利

登録したサブスクと設定は端末内にあり、開発者はそれを保持していません。そのため、削除は利用者ご自身で完結します。

  • 登録したサブスクは、アプリ内で個別に削除できます
  • アプリを削除すると、端末内に保存されたデータと設定も削除されます
  • 通知の許可は、iOS の「設定」からいつでも取り消せます
  • 使い方の統計は、アプリの「設定」→「プライバシー」でいつでもオフにできます。オフにすると、端末に残っていた送る前の統計と乱数の ID も削除されます
  • 端末のバックアップ（iCloud バックアップなど）を利用している場合、アプリのデータは Apple の仕組みによってそのバックアップに含まれます。バックアップの管理は iOS の「設定」から行えます

開発者が保持するアカウントは存在しないため、退会手続きは必要ありません。送信済みの使い方の統計とテンプレートの報告には身元が分かる情報が無く、開発者にもどの統計や報告がどなたのものか分からないため、個別の開示や削除には応じられません。すでにお送りいただいたお問い合わせメールの削除をご希望の場合のみ、下記の連絡先へお知らせください。
